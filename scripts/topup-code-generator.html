All values must belong to the SAME environment you send the request to. A code built with dev's secrets only works against dev; local secrets only against local. Mixing them is the #1 cause of "Invalid X-WM-Topup-Code".

Handle secrets like passwords. Only use this page from a trusted machine. Nothing is stored or sent anywhere — values live only in this tab and vanish when you close it.
